# AIcode 部署指南

## 1. 环境要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| Python | 3.8+ | 后端运行环境 |
| MySQL | 5.7+ / 8.0 | 数据库，字符集 utf8mb4 |
| Node.js | 14+ | 可选，用于前端静态服务器 |
| MongoDB | 4.x | 可选，对话记录相关脚本使用 |

## 2. 目录结构

```
AIcode/
├── back_end/              #7 后端服务
│   ├── app.py             # Flask 主程序（接口、配置、启动）
│   ├── requirements.txt   # Python 依赖
│   └── resource/          # 星火 API 文档等资源
├── front_end/             # 前端页面
│   ├── login/             # 登录页
│   ├── dialog/            # 聊天页（流式 / WebSocket）
│   ├── data/              # 数据分析页
│   └── index.html         # 登录入口页
├── sql/
│   ├── mysql/             # MySQL 建表与初始化脚本
│   │   └── main.sql       # 数据库初始化入口
│   └── mongo/             # MongoDB 脚本
└── docs/                  # 项目文档
```

## 3. 数据库初始化

### 3.1 MySQL
1. 确认 MySQL 服务已启动，且支持 utf8mb4 字符集
2. 进入 `sql/mysql/` 目录，执行初始化入口脚本：

```bash
mysql -u root -p < main.sql
```
或在 MySQL 客户端中：
```sql
source /path/to/sql/mysql/main.sql;
```

`main.sql` 会依次创建并初始化以下 7 张表：
`user`、`role`、`permission`、`chatting_records`、`behavior_statistics`、`preferences`、`preference_statistics`

所有建表与建索引均采用幂等写法，可重复执行。

### 3.2 MongoDB（可选）
`sql/mongo/` 下含对话记录相关脚本，按需执行。

## 4. 后端部署

### 4.1 安装依赖
```bash
cd back_end
pip install -r requirements.txt
```
核心依赖：Flask、flask-mysql-connector、flask-socketio、flask-cors、werkzeug、itsdangerous、requests、simple-websocket

### 4.2 修改配置
编辑 `back_end/app.py` 中 `Config` 类，按实际环境修改：

```python
class Config:
    MYSQL_HOST = "localhost"        # MySQL 地址
    MYSQL_PORT = 3306               # MySQL 端口
    MYSQL_USER = "root"             # MySQL 用户名
    MYSQL_PASSWORD = "123456"       # MySQL 密码
    MYSQL_DB = "AIcode"             # 数据库名
    SECRET_KEY = "..."              # token 签名密钥（生产环境务必修改）
    SPARK_API_PASSWORD = "..."      # 星火平台申请的 API Password
```

> **重要：** `SPARK_API_PASSWORD` 需替换为你在讯飞星火平台申请的 API Password，否则对话接口不可用。

### 4.3 启动后端
```bash
python app.py
```
默认监听 `0.0.0.0:6008`（支持 HTTP 与 WebSocket）。

启动后访问 `http://localhost:6008/health` 验证，返回 `{"code":0,"msg":"服务运行中"}` 即成功。

## 5. 前端部署

### 5.1 配置接口地址
前端通过 `API_BASE` 访问后端，需与后端地址一致：

| 文件 | 变量 | 示例值 |
|------|------|--------|
| `front_end/login/login.js` | `API_BASE` | `http://localhost:6008` |
| `front_end/dialog/app.js` | `API_BASE` | `http://localhost:6008` |
| `front_end/dialog/chat-stream.js` | `API_BASE` | `http://localhost:6008` |

### 5.2 启动前端静态服务
任选一种方式在 `front_end/` 目录启动静态服务器：

```bash
# 方式一：Python 内置
python -m http.server 6020

# 方式二：Node http-server
npx http-server -p 6020
```

访问 `http://localhost:6020/login/login.html` 进入登录页。

### 5.3 跨域说明
后端已开启 CORS（`flask-cors` + `after_request`），允许前端跨端口调用。WebSocket 通过 `flask-socketio` 的 `cors_allowed_origins="*"` 允许跨域连接。

## 6. 访问验证

| 验证项 | 方式 |
|--------|------|
| 后端健康 | `GET http://localhost:6008/health` |
| 登录页 | 浏览器打开 `http://localhost:6020/login/login.html` |
| 流式聊天 | 登录成功后自动跳转，或直接访问 `front_end/dialog/chat-stream.html` |
| WebSocket 聊天 | 直接访问 `front_end/dialog/index.html` |

## 7. 生产环境建议

| 项 | 开发环境（当前） | 生产环境建议 |
|----|------------------|--------------|
| 后端启动 | `socketio.run` + werkzeug | gunicorn + eventlet（`gunicorn -k eventlet app:app`） |
| CORS | `*` 全放行 | 限定具体域名 |
| SECRET_KEY | 硬编码 | 环境变量注入 |
| 登录失败计数 | 内存字典 | Redis |
| MySQL 密码 | 明文配置 | 环境变量 / 配置中心 |
| 前端 | 静态服务器 | Nginx 反向代理 + 静态托管 |
| HTTPS | 无 | Nginx 配置 SSL 证书 |
